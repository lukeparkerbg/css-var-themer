Welcome!

This page uses CSS variables that you can theme with the CSS Var Themer extension.

Try these steps:

  1. Click the CSS Var Themer extension icon
  2. Click "Extract CSS Variables"
  3. Enter a theme description like "dark mode" or "ocean blue"
  4. Give it a name and click "Generate Theme"
  5. Click "Apply" to see the changes!
